# Basic output example

Upload this code, then open **Tools → Serial Monitor**. Make sure the baud rate dropdown (bottom right) is set to **115200** to match your code.

You'll see a running log of what your tinyCore is doing. This is invaluable for understanding program flow and diagnosing issues.

## Open it

- **tinyStudio (web)** — [open this project](https://app.tinystudio.cc/Mister-Industries/tinyStudio-examples/basics/serial-monitor-basic-output)
- **tinyStudio (desktop)** — Examples tab → *Basic output example*
- **Arduino IDE** — open `serial-monitor-basic-output/serial-monitor-basic-output.ino`
