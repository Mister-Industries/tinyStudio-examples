# tinyMP3Player

---

A straightforward SD card music player. Drop `.mp3` files into the root of your SD card and tinyMP3Player will find and play them in order, automatically advancing to the next track when each one finishes.

Control playback from the Serial Monitor with single-key commands for play/pause, next/previous track, and volume. If the optional RX button is installed, a single press toggles play/pause and a quick double-press skips to the next track.

  **SD card** with `.mp3` files

  **Libraries:** ESP32-audioI2S
