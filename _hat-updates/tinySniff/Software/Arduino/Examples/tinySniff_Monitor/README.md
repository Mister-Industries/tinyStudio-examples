# Basic Demo

---

Reads the three sensors and graphs them. That's the whole sketch. No menu, no commands, no SD card.

  **Libraries:** none, raw ADC only

Plug the tinyCore in over USB-C, hit **Connect**, and pick your port. This panel appears under every demo below, and the later ones let you type commands to the board.
